# Learning log

The learning log now lives on the website as a development journal:

- **Read it:** https://git-ebrahim.github.io/learning-experimentation/#/journal
- **Source:** one Markdown file per entry in [`web/src/journal/entries/`](web/src/journal/entries/)
- **Add an entry:** follow [`web/src/journal/README.md`](web/src/journal/README.md)

Each entry records the question, the approach, the findings, and the evidence, and links to its pull requests and to the page on the site that shows it working.
